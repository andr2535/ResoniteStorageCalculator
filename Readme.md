# ResoniteStorageCalculator

ResoniteStorageCalculator converts the Records.json into a format that is easier to understand, and use to reduce your cloud storage consumption in Resonite.

Records.json can be gotten by sending the message "/requestRecordUsageJSON" to the Resonite contact, which is in all users contact list by default.

## Building

ResoniteStorageCalculator should build like most cargo based projects:

```shell
cargo build --release
```
